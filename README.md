# SCADA-Based-Automatic-Lighting-Control-System
Arduino-based automatic lighting control system using a conventional PID controller (sketch_pid) and an adaptive PID controller with continuous gain scheduling (sketch_adaptiv).
Uses an APDS-9930 light sensor, an X9C103S digital potentiometer and an I2C LCD for illuminance regulation and monitoring.
Implements gamma correction, hardware dead-zone compensation and serial communication for PC-based supervision.
